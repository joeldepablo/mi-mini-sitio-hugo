# Mi primer artículo

En este artículo voy a hablar sobre Hugo.

Hugo es un generador de sitios web estáticos que permite crear páginas utilizando Markdown y plantillas.

## Ventajas de Hugo

- Es rápido.
- Permite crear páginas estáticas.
- Utiliza plantillas reutilizables.
- Facilita la organización del contenido.
